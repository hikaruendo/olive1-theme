# 予約台帳（Google スプレッドシート）の設定

台帳：「Olive1 予約台帳 2026」（hikaru.endo@kando1.com のドライブ）

## 1回だけやること（5分）

1. 台帳を開く → メニュー「拡張機能」→「Apps Script」
2. 最初からある `コード.gs` の中身を全部消し、`reserve-sheet.local.gs`（SECRET 入り・Git に入れないファイル）の中身を貼って保存
3. 上の関数の選択で `setup` を選んで「実行」→ 権限の確認が出たら自分のアカウントで許可（「このアプリは Google で確認されていません」→「詳細」→「（安全ではないページ）に移動」）。「設定しました。SECRET: 登録済み」と出れば OK
4. 右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
5. 「デプロイ」→ 出てきた **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）を Claude に渡す → Vercel の `SHEET_WEBHOOK_URL` に入れる
6. 台帳を開き直すとメニューに「Olive1」が出る

## 毎日の使い方

- 予約が入ると1行増える（状態＝予約）
- 銀行振込の入金を確認したら、状態を「入金済み」に変え、入金日時を入れる
- カードは自動で「入金済み」になる（入金日時・決済本数・決済額・Stripe決済ID も入る）。予約と決済で本数が違うと「備考」に出る
- メニュー「Olive1」→「入金済みに本番号を振る」で、入金の早い順に番号が入る（2本なら「12-13」）
- キャンセルは状態を「キャンセル」に（その本数は残りに戻る）。**行は消さない**
- 残り本数は「Olive1」→「残り本数を見る」。予約ページにも「残り◯本」が出る
- 残りが 0 になると予約ページは自動で売り切れ表示になる

## 注意

- 列の順番を変えない・列を挿入しない（スクリプトは列の位置で読む）。並べ替えやフィルタは OK
- `TOTAL`（本数）を変える時はスクリプトの1行目を書き換えて保存 →「デプロイを管理」→ 鉛筆 →「新バージョン」で更新
- スクリプトを直したら、毎回「新バージョン」でデプロイし直さないと Web アプリには反映されない（URL は変わらない）
